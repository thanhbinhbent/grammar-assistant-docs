7 Enhancement Modes ​

1. Fix Grammar ✓ ​

Correct grammar and spelling errors.

Example:

Input:  "She don't like apples and banana"
Output: "She doesn't like apples and bananas"

2. Natural 💬 ​

Make content natural and conversational.

Example:

Input:  "I am writing to inquire about the status"
Output: "I'm reaching out to check on the status"

3. Formal 👔 ​

Professional, business-appropriate tone.

Example:

Input:  "Hey, can you send me that file?"
Output: "Hello, could you please send me that file?"

4. Polite 😊 ​

More polite and courteous communication.

Example:

Input:  "Send me the report"
Output: "Would you mind sending me the report?"

5. Shorter 📉 ​

Reduce length, keep key points.

Example:

Input:  "In spite of the fact that it was raining heavily"
Output: "Although it was raining heavily"

6. Longer 📈 ​

Expand with more details.

Example:

Input:  "The project is good"
Output: "The project demonstrates excellent quality and shows great attention to detail"

7. Creative 💡 ​

Make content creative and engaging.

Example:

Input:  "The product works well"
Output: "This product truly shines in its performance"

Custom Enhancement Options ​

Create up to 5 custom prompts for your specific needs.

How to Create ​

  1. Settings (⚙️) → "Custom Enhancement Options"
  2. Click "Add Custom Option"
  3. Enter Label and Prompt
  4. Save

Best Practices ​

Keep prompts short (2-5 words):

  • ✅ "Add emojis"
  • ✅ "Simplify for beginners"
  • ✅ "Remove jargon"
  • ❌ "Please make this text more simple and easy to understand for people who are new to this topic"

Why? Shorter prompts = Faster response + Lower cost

AI Provider Comparison ​

OpenAI ​

  • Models: gpt-4o-mini, gpt-4o, gpt-4, etc.
  • Default: gpt-5-nano
  • Best for: High quality, general purpose

Google Gemini ​

  • Models: gemini-2.5-flash, gemini-1.5-pro, etc.
  • Default: gemini-2.5-flash
  • Best for: Cost-effective alternative

Switch anytime in Settings without losing preferences.

Token Usage Tracking ​

Real-time monitoring of API usage and costs.

What's Tracked ​

  • Input tokens (your text)
  • Output tokens (AI response)
  • Estimated cost per request
  • Total tokens and spending

Where to View ​

  • Main window: Current session stats
  • Settings: Detailed history and totals
  • Reset: Clear tracking data anytime

INFO

Cost estimates are for OpenAI. Gemini costs may differ.

Performance ​

Response Time: 1-3 seconds typical

  • Depends on: Model, text length, network speed

Resource Usage:

  • App size: ~20MB
  • Memory: <100MB
  • No background processes

Privacy & Security ​

What We Store Locally ​

  • ✅ API keys (secure keychain)
  • ✅ Settings and preferences
  • ✅ Custom enhancement options
  • ✅ Token usage statistics

What We DON'T Collect ​

  • ❌ Your text content
  • ❌ Analytics or telemetry
  • ❌ Personal information
  • ❌ Usage patterns

Your text is only sent to your chosen AI provider when you press Cmd+Shift+G.

Limitations ​

Current constraints to be aware of:

  • Platform: macOS only (10.15+)
  • Shortcut: Cmd+Shift+G fixed (not customizable)
  • Token limit: ~4000 tokens per request
  • Internet: Required for AI API calls
  • Cost: API usage charged by provider

Tips for Best Results ​

✅ Do ​

  • Use complete sentences or paragraphs
  • Select appropriate enhancement mode
  • Review AI output before using
  • Keep text under 2000 words

❌ Don't ​

  • Submit code or binary data
  • Share sensitive information
  • Rely 100% on AI (always review!)
  • Send extremely long texts (split them)
