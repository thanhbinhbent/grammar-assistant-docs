What is Grammar Assistant? ​

Grammar Assistant is a macOS application that brings AI-powered writing enhancement to your fingertips. Select text anywhere, press Cmd+Shift+G, and instantly improve your writing.

Key Features ​

⌨️ One Global Shortcut

  • Press Cmd+Shift+G from any application
  • Works in browsers, text editors, email clients, chat apps
  • Automatic clipboard integration

🤖 AI-Powered Enhancement

  • OpenAI GPT or Google Gemini support
  • 7 enhancement modes: Fix Grammar, Natural, Formal, Polite, Shorter, Longer, Creative
  • Custom enhancement options (up to 5)
  • Typical response time: 1-3 seconds

📊 Token Usage Tracking

  • Real-time API usage monitoring
  • Cost estimates and spending tracking
  • Helps manage your API expenses

🔒 Privacy First

  • API keys stored locally on your Mac
  • No cloud storage of your text
  • No analytics or tracking

Use Cases ​

  • Professional emails and business communication
  • Blog posts, articles, and social media content
  • Code documentation and README files
  • Academic papers and essays
  • Customer support responses
  • Important messages and chat conversations

How It Works ​

  1. Select text in any app
  2. Press Cmd+Shift+G
  3. Choose enhancement mode
  4. Copy improved text
  5. Paste back to your app

Simple and fast! 🚀
