Grammar Assistant Documentation ​

Official user documentation for Grammar Assistant.

🚀 Quick Start ​

Development ​

bash
npm run docs:dev

Visit http://localhost:5173/grammar-kit/

Build ​

bash
npm run docs:build

Output: docs/.vitepress/dist/

Preview Build ​

bash
npm run docs:preview

📚 Documentation Structure ​

docs/
├── .vitepress/          # VitePress configuration
│   └── config.ts        # Site config, navigation, sidebar
├── guide/               # User guide
│   ├── what-is-grammar-assistant.md
│   ├── getting-started.md
│   ├── installation.md
│   ├── configuration.md
│   └── features.md
├── public/              # Static assets (logos, images)
└── index.md            # Homepage

🎨 Customization ​

Update Navigation ​

Edit docs/.vitepress/config.ts:

typescript
nav: [
  { text: 'Home', link: '/' },
  { text: 'Guide', link: '/guide/getting-started' }
]

Update Sidebar ​

typescript
sidebar: [
  {
    text: 'Introduction',
    items: [
      { text: 'What is Grammar Assistant?', link: '/guide/what-is-grammar-assistant' }
    ]
  }
]

📖 Writing Docs ​

Markdown Features ​

VitePress supports:

  • Standard Markdown
  • Custom containers (::: tip, ::: warning, ::: danger)
  • Code blocks with syntax highlighting
  • Tables
  • Emojis

Example ​

markdown
# Page Title

Some content here.

::: tip
This is a helpful tip!
:::

\`\`\`typescript
const example = 'code';
\`\`\`

🚢 Deployment ​

Documentation automatically deploys to GitHub Pages when you push to main branch.

URL: https://thanhbinhbent.github.io/grammar-assistant/

GitHub Pages Setup ​

  1. Go to repository Settings → Pages
  2. Source: Select "GitHub Actions"
  3. Push changes to trigger deployment

📝 Contributing ​

When updating docs:

  1. Match actual implementation
  2. Keep user-focused (no developer content)
  3. Use clear examples
  4. Test locally before pushing
